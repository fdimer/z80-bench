Screen

Click the picture and type: letters, digits and symbols come out as typed (the page presses the Spectrum keys that give that character: SYMBOL SHIFT for the symbols, CAPS SHIFT for capitals). Shift is CAPS SHIFT, Ctrl or Alt is SYMBOL SHIFT, Backspace is DELETE, the arrows move the cursor and Escape is BREAK. Each key on the drawing shows the keyword it gives at the K cursor (above), the SYMBOL SHIFT symbol (red) and the extended-mode word (green below); on the digits the word above is the CAPS SHIFT function. CAPS SHIFT and SYMBOL SHIFT stay down for the next key. Load ROM takes the 48K's 16 KB ROM (CRC DDEE531F); it is not included, and your browser keeps it, so you only load it once.

The picture is built the way the ULA builds it: 312 lines of 224 T-states, the border from port FE and, for the 192 lines of the picture, the bitmap and attribute bytes read from the screen memory at the moment they are drawn, so programs that change the screen or the border while it is drawn show the effect. While the machine is paused, the white line and red mark show where the beam is.

Clicking the Z80's CLK pulses one clock. The pins follow the machine clock by clock. When the ULA holds the CPU (a cycle that uses 4000h–7FFFh or an even port while the picture is being drawn), the bus timing shows the held T-states as TH and the ULA's CPU CLK pin stays high. On the ULA, the lower RAM's pins (RAS, CAS, WE, A0–A6, D0–D7) follow whoever uses that RAM at each T-state: during the picture the ULA reads a bitmap byte, its attribute, the next bitmap byte and its attribute in every 8 T-states (RAS and CAS low, the byte's column on A0–A6 and the byte on D0–D7), and the CPU's accesses to 4000h–7FFFh and its refresh cycles there come through the ULA too. They are shown T-state by T-state, not edge by edge. The video outputs U, V and Y are analogue and show ~. Pin numbers are from the issue 4A/4B circuit diagram.

Program

Standard Zilog syntax, one instruction per line. Labels end with :; comments start with ;. Directives: ORG, EQU, DB, DW, DS, END. Numbers: 1Fh, 0x1F, $1F, %1010, 'A', and $ for the current address. Undocumented instructions (IXH, SLL, OUT (C),0) are accepted. Code starts at the Load at address; an ORG in the source overrides it. Import a file with the button or by dropping it on the editor.

Hex bytes separated by spaces or newlines. Text after ; is ignored. Write 0100: to continue loading at another address. Intel HEX files (lines starting with :) are also accepted and keep their own addresses. Raw binary ROM images (.bin, .rom) import here as hex. Memory

Scroll through all 64 KB as the CPU sees it now: ROM where a ROM half is switched on, RAM elsewhere. Click a byte to edit it (the change goes to the RAM). Blue marks the instruction being executed, amber marks bytes written by the last instruction, underline marks the top of the stack. With Follow PC ticked, each step brings the current instruction back into view; untick it to keep watching another area.

Memory bitmap

Point at the bitmap to read a byte; click to show it in Memory.

Every bit of memory is one pixel. Each byte is a row of 8 pixels (bit 7 on the left) and each strip is one 256-byte page, read top to bottom; each band holds 8K. The ROM's two halves come first, then the 64K of RAM; the tint shows what each part of the RAM is used for (the screen memory follows the 6845's start address). The red mark is the program counter and the blue mark the stack pointer, shown on the bands the CPU sees at this moment.

    Spectrum hardware memory · ULA · contention · port FE

    The ULA (IC1) makes the 3.5 MHz clock, draws the picture from the screen memory at 4000h–5AFFh, asks for an interrupt at the start of every frame (50 a second) and answers every even port (port FE): reading it gives the keyboard's half-rows chosen by the high byte of the address (bits 0–4) and the EAR input (bit 6); writing it sets the border (bits 0–2), MIC (bit 3) and the speaker (bit 4). The lower 16K of RAM is the ULA's: while it reads the screen, a CPU cycle that uses 4000h–7FFFh, or an even port, is held until it is done (contention). The ROM is at 0000h–3FFFh and the upper 32K of RAM at 8000h–FFFFh run at full speed.
